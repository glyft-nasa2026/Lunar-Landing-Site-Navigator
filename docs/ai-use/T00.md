## Choices the AI made that the contract doesn't spell out

Each is one line in the code and easy to change. P1 to confirm or overrule.

| Choice | Where | Why |
|---|---|---|
| A whole-number column and row in the height grid sits exactly on a stored value (no half-cell shift) | `core/dem.ts` | The contract's `col = (x - x_min_m) / pixel_m`, read literally. T04 must write the grid the same way |
| A height-map cell holding `nodata` counts as 0 m | `core/dem.ts` | One hole would otherwise drag its neighbours down by 16 km |
| `covers()` is false north of `min_lat`, even inside the square | `core/dem.ts` | The corners of the square lie north of 80 S, where the file has no data |
| A time outside the table returns the nearest end row from `vectorsAt`; `series` leaves such times out; `nextFlip` stops at the end of the table | `core/ephemeris.ts`, `core/windows.ts` | F2: a time outside the range must not crash |
| `series` does not include its end time: 30 days hourly is 720 samples | `core/windows.ts` | Each sample stands for the hour after it, so percentages add up |
| Under one hour a countdown reads `0 h 20 min` | `core/windows.ts` | The contract gives only `3 d 4 h` and `5 h 20 min` |
| The page address holds the live scenario, the selection, the range and the mode as well as the pinned scenarios | `state.ts` | F17 says a link reopens the same comparison |
| Coordinates are kept to 6 decimal places (3 cm) | `state.ts` | Short addresses, and a restored scenario equals the saved one exactly |
| The live scenario's colour is `--accent`; pinned ids are `a`, `b`, `c`; a pin takes the first free slot | `state.ts` | F5 fixes A, B, C colours only for pinned scenarios |
| `setData()`, `stateToAddress()`, `restoreFromAddress()`, `LIVE_ID`, `PIN_SLOTS`, `MAX_PINNED` are exported besides the contract's list | `state.ts` | `main.ts` and the tests need them; modules can read `MAX_PINNED` to disable the Pin button |
| `MOON_RADIUS_KM` and `DEFAULT_EYE_M` live in `core/types.ts` | `core/types.ts` | One copy of each number for `dem.ts`, `geometry.ts` and T05 |
| `#side` and `#bottom` wrappers and a `#status` line in `index.html`, beside the eight slots | `index.html` | The side column and bottom row need a parent; "Data not loaded" needs a place that is not a module |
| `@types/node` added | `package.json` | Tests read data files from disk |
| A decade that failed to download counts as the end of the table for anything that starts before it: the series stops there and a countdown that finds nothing before it reads "No sunrise in the next 60 days" | `state.ts` | Contract section 4 says such a decade "reads as outside the table"; `Flip` has no way to say "unknown" |
| A decade file is refused when shorter than its rows need; a longer one is accepted | `core/ephemeris.ts` | The same rule `parseEphemeris` has had since the first delivery |
