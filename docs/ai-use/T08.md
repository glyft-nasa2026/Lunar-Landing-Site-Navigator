## Choices the AI made that the task doesn't spell out

- A Live card sits above the pinned cards, so a person can go back to the live scenario after selecting a pinned one without editing anything.
- The cards are kept and updated in place, one per scenario id, never rebuilt. A box applies on the mouse press that takes the focus away, and a card replaced between that press and the release gets no click.
- A press on one of the panel's buttons whose release lands beside it, because a message line appeared or went meanwhile, still counts as a click if the pointer is where the button was at the press. The lasting cure is in `scenarios.css` (keep the message line's space), which is T23's file.
- Latitude and longitude take an optional sign, digits and an optional decimal point. Hex, binary, octal and exponent forms are rejected with the same message as a word.
- The dropdown's first entry reads "Typed coordinates" at all times. The status line says whether the site list is loading or failed.
- A box applies its value on Enter or when the box loses focus, not on every key press. The time box waits longer: while keys are typed into it, it applies only on Enter or when it loses focus, because Chromium reports each part of a date as it is typed. A value set in one go (the calendar picker, a paste) applies at once. A rejected value stays in the box with its message; it is replaced, and the message cleared, the next time the live scenario moves some other way.
- A time at or after the table's last row is rejected: the readout needs the hour after it.
- While the table is loading, the time box checks only the format, not the range.
- The time box is a browser date-time picker read as UTC. Some browsers show it in a 12-hour format; the label says UTC and the value is UTC.
- "Smooth Moon, no terrain" comes from `skylineFor(...).terrain`. Until T05 merges, `horizon.ts` returns a flat skyline everywhere, so the note shows for every site, the crater floor included. It goes away by itself where T05 finds terrain.
