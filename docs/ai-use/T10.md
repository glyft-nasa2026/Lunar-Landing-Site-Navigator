## Choices the AI made that the task doesn't spell out

- **The Sun line is the top of the disc** (`sunAbove + 0.267°`), not its centre. The readout calls the Sun up while any part of the disc clears the skyline (`sunFrac > 0`), so only the top edge crosses zero when the countdown does. The centre would cross up to a few hours later at the pole. The legend says "Sun (top of the disc)".
- **Exact crossings.** The samples are hourly. Wherever a line changes sign between two samples, a point at zero is added at the exact time from `flipFor` (core's `nextFlip`), so the line meets zero at the countdown's minute, not up to an hour off. It falls back to straight-line interpolation if `flipFor` has no answer.
- **Date axis**, not "0 d … 30 d" as in the design: after Earlier or Later the window no longer starts at the scenario's time, so days from the start would mislead.
- **Earlier and Later are disabled while a pinned scenario is selected.** They move only the live window (contract section 4); a pinned scenario's window always starts at its own time.
- **The y axis** is symmetric about zero, at least ±8°, widened in 4° steps to fit the data.
- **Smooth drags.** The traces are rebuilt only when the site, window or data changes. A drag changes only the marker, and Plotly.react sees the same arrays and redraws only the shapes. On a phone a vertical swipe still scrolls the page (`touch-action: pan-y`); a sideways drag scrubs.
- **Times go to Plotly as UTC strings with no zone** (`plotTime`), never as milliseconds. Plotly shows a zone-less string as written and a number in the browser's local time. The pointer still maps pixels to milliseconds from the window's own two times, so nothing else changed.
- **A press on a pinned scenario's chart is a click, never a drag.** It sets the live time once; the chart then shows the live window, which the press was not made in.
- **Fewer than two samples with the table loaded is final, not a wait.** `state.ts` hands over the table only when every decade the scenarios need has arrived or failed, so the module says why there is no chart (`emptyNote`) and keeps "Loading" for `eph` null.
