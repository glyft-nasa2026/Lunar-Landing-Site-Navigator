## Preview behaviour

`.github/workflows/preview.yml` runs tests and a production build for same-repository PR updates
and pushes to main. After successful checks it uploads to the `preview` production branch of
the Cloudflare Pages project `darksight`, which serves `https://darksight.space`.
Fork PRs cannot use the deployment credential. One concurrency group cancels superseded runs.
The domain shows the latest passing branch build; each deployment contains that branch's code.
The immutable Pages deployment URL also identifies the individual build. The workflow is
delivered separately in [PR #9](https://github.com/glyft-nasa2026/Darksight/pull/9) so it
can run for every ticket while T12 remains in review. The first T12 workflow run passed
with 143 tests and a production build: [run 43551435281](https://github.com/glyft-nasa2026/Darksight/actions/runs/43551435281).
Cloudflare reports the custom domain and certificate active; an actual Chromium browser
opened `https://darksight.space/` with HTTP 200 and the Darksight title.
After merging T20, CI and the preview workflow passed for commit `1222bfb`
([preview run](https://github.com/glyft-nasa2026/Darksight/actions/runs/43554111338)).
Cloudflare's deployment metadata matched that commit. Live Chromium verification confirmed
terrain loaded, all six T20 public data files matched the branch byte-for-byte, the camera
switch worked, and there were no uncaught browser errors.

P3 still owns T21's CI, deploy-branch/homelab workflow and branch protection. This exception adds only
the Cloudflare preview workflow and leaves those tasks with P3. Deployment credentials are
kept in GitHub Actions secrets, with the account ID in a repository variable.

Lighting and stretched-height shadows illustrate the terrain. All visibility text comes from
`core/`; no Sun or Earth angle is calculated in the scene. The Earth texture is a stylised
canvas illustration. The current T00 skyline is flat until T05 replaces it, so terrain shadow
images and core visibility can differ at times when only the terrain hides the Sun.

T21 subsequently merged its main-only deploy-branch/homelab pipeline. The custom domain
for latest ticket previews points to Cloudflare Pages; P3 should preserve that DNS target
when configuring the separate homelab mirror. No T21 workflow file was edited by T12.
