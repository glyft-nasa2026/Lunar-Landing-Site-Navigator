## Choices the AI made that the task doesn't spell out

- **An early edit cancels the example.** A map click, a typed site or time, or a pin made before `sites.json` arrives is kept, and no example is built. Otherwise the example would overwrite the first click on a slow connection. Added to the contract.
- **Built at most once per address read.** The site list arriving again does not rebuild it after the user unpinned A.
- **Written to the page address** like any other change, so the share button copies the example and a reload shows it at the hour it was built.
- **Real ids before mock ids.** With both pairs in the list, `shackleton-rim` and `shackleton-floor` win. A pair with a missing or non-numeric latitude counts as absent.
- **Pasting the plain link into a tab that is already open** gives the default live site and nothing pinned: the example is built when the site list arrives, and in that tab it already has.
