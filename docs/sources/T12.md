No external terrain or imagery was downloaded. Browser checks generate synthetic height grids
from the contract and a deliberately accelerated Sun table, injected through intercepted browser
requests. The larger grid checks metadata compatibility, not scientific accuracy of real LOLA data.
The Earth sprite is original stylised canvas art rather than a sourced geographic map.
