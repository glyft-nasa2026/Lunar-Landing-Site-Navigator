No external terrain or imagery was downloaded by this task. Browser checks use the merged
public files (T04's LOLA height map, T01's Sun/Earth table, T20's mock sites), then generate isolated synthetic height grids
from the contract and a deliberately accelerated Sun table, injected through intercepted browser
requests. The synthetic grids check metadata compatibility, not scientific accuracy.
The Earth sprite is original stylised canvas art rather than a sourced geographic map.
